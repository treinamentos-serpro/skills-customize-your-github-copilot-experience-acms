
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Desenvolva um jogo da Forca em Python para praticar strings, listas, seleção aleatória, loops, condicionais e entrada de dados do usuário.

## 📝 Tarefas

### 🛠️ Preparar a palavra e o estado do jogo

#### Descrição
Escolha aleatoriamente uma palavra da lista fornecida no código inicial e prepare as variáveis necessárias para acompanhar a partida.

#### Requisitos
O programa concluído deve:

- Selecionar uma palavra aleatória da lista predefinida.
- Exibir a palavra como letras ocultas, mantendo visíveis as letras já adivinhadas.
- Registrar as letras tentadas e definir um limite de palpites incorretos.

### 🛠️ Implementar os palpites e o encerramento da partida

#### Descrição
Crie o loop principal para receber palpites, atualizar o progresso e encerrar a partida quando o jogador vencer ou ficar sem tentativas.

#### Requisitos
O programa concluído deve:

- Solicitar um palpite de uma letra e informar quando a letra não estiver na palavra.
- Atualizar e exibir o progresso da palavra e o número de palpites incorretos restantes.
- Encerrar quando todas as letras forem reveladas ou o limite de palpites incorretos for atingido.
- Exibir uma mensagem de vitória ou derrota; em caso de derrota, revelar a palavra escolhida.
